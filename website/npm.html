Intelligence Architectures

Four personas. One terminal.

Each persona is a fully-tuned Intelligence Architecture with its own tools, RAG parameters, and system prompt.

Scholar

Deep research, semantic PDF indexing, and academic citation. Index entire paper corpora and query them with academic precision.

  • /citeGenerate inline citations from indexed documents
  • /bibtexExport a full BibTeX bibliography from your session
  • /globalSearch across ALL indexed datasets (Relational RAG)
  • /snapshotSave a named checkpoint of your session state
  • /handoffTransfer context to another persona
  • /exportSave session history to a Markdown file
  • /statsView token usage and system health

--mount <dir>   Mount a folder of PDFs for indexing

--pages <range>   Index specific pages, e.g. 1-10

scholar session
$ snapmind-ai --persona scholar --mount ./papers --pages 1-50

✓ Chunk size: 1000 | Overlap: 200 | K: 5

How it Works

Up and running in 4 steps.

From installation to AI-powered terminal sessions — get started in under 2 minutes.

STEP 01
Easy Setup

Install

Install globally via npm. Node.js 18+ required. Optionally install Ollama for local-first mode.

npm install -g snapmind-ai
STEP 02
Secure Config

Configure

Set your default provider and API keys. Keys are stored in your OS-native keychain — never in plaintext.

snapmind-ai config
STEP 03
Pick Persona

Launch Persona

Choose a persona and mount your data. SnapMind indexes files and starts the vector store automatically.

snapmind-ai --persona coder --repo <url>
STEP 04
AI-Powered

Query & Create

Chat naturally with your data. Use persona commands, export results, or hand off to another AI architecture.

snapmind-ai "Summarize findings"
CLI Reference

Every command. Every flag.

Full reference for the SnapMind AI CLI — commands, flags, and vault management.

COMMANDS

CommandDescription
snapmind-aiLaunch interactive persona selector
snapmind-ai configOpen the configuration wizard
snapmind-ai config set <key> <value>Set a config value directly
snapmind-ai search <query>Global search across all indexed datasets
snapmind-ai maintenanceClean up orphan sessions and stale caches
snapmind-ai vault set <provider>Securely store an API key in OS Keychain
snapmind-ai vault delete <provider>Remove an API key from the Keychain

FLAGS

FlagDescription
--airgapForce 100% offline mode (requires Ollama)
--persona <name>Launch directly into a persona
--mount <path>Mount a local directory for indexing
--repo <url>Clone and index a GitHub repository
--watchAuto-sync vector index on file changes
--pages <range>Index specific PDF pages (Scholar only)
