Getting Started (CLI Quickstart)

STEP 1: Prerequisites

Before installing SnapMind AI, make sure you have the following installed on your machine:

  • Node.js: Version 18.x or above.
  • npm: Normally comes with Node.js.
  • Ollama (Optional): Required only if you want to run completely local/offline LLMs.
STEP 2: Installation

SnapMind can be installed globally via npm. Open your terminal and run the following command:

npm install -g snapmind-ai
Note: On Linux/macOS, you might need to use sudo depending on your npm setup.
STEP 3: Configuration

Once installed, you need to configure your LLM providers. Run the config wizard to set up your API keys and default models.

snapmind-ai config

Follow the interactive prompts to add your keys (e.g., OpenAI, Anthropic, Gemini). Your keys will be securely stored in your OS keychain, never as plaintext.

STEP 4: Usage

You are now ready to start using SnapMind! Launch a persona directly from the terminal. For example, to use the Coder persona on a specific repository:

snapmind-ai --persona coder --repo https://github.com/your/repo.git

Or, use the Scholar persona on a local folder of PDFs:

snapmind-ai --persona scholar --mount ./my_papers

Usage Details

Available Personas

  • scholar: Advanced RAG over PDFs with citation support.
  • coder: AST-aware repository indexing and architecture planning.
  • analyst: High-fidelity CSV mapping and markdown trend generation.
  • writer: Prose synthesis taking context from other personas.

Important Flags

  • --airgap: Force offline mode using Ollama only.
  • --watch: Sync vector index dynamically when files change.

Managing Data

All embeddings and histories are stored safely inside the local .snapmind_cache folder in your current directory. To perform routine cleanup, run:

snapmind-ai maintenance
