Features

One package. Infinite intelligence.

Every tool a power user needs — right inside the terminal. No cloud lock-in. No telemetry. Just results.

4 Specialized Personas

Scholar, Coder, Analyst, and Writer — each with tailored tools, system prompts, and RAG configurations.

Hybrid RAG

LanceDB powers vector similarity search + Full-Text Search (FTS) for precision multi-modal retrieval.

Secure API Vault

Keys stored in your OS-native keychain via keytar — never in plaintext, never on disk.

Session Memory & Snapshots

Named session snapshots for branching research paths. Resume any conversation exactly where you left off.

Multi-Agent Handoff

Switch personas mid-session with /handoff while preserving full conversation context and vector state.

Auto-Routing

Semantic intent detection automatically selects the best persona for your query. Complexity-based model routing.

Global Cross-Persona Search

Query across ALL indexed datasets from any persona with /global <query> — Relational RAG.

Airgap Mode

Force 100% offline operation with --airgap. All processing stays on your machine via Ollama.

Theme Engine

Cyberpunk, Matrix, and Default terminal color schemes. Your terminal, your aesthetic.

Supported Providers

Local or Cloud. Your choice.

Security

Private by design.

Your data never leaves your machine unless you explicitly choose a cloud provider.

OS Keychain Storage

API keys are never stored in plaintext. All credentials use the OS-native keychain via keytar.

Airgap Mode

The --airgap flag ensures zero network traffic. All LLM inference stays on your machine via Ollama.

Zero Telemetry

SnapMind does not phone home. No usage data, no analytics, no crash reports. What you do is yours alone.

Local Vector Store

All indexed data is stored locally in .snapmind_cache/lancedb/ — private, persistent, and portable.

FAQ

Common questions.

All API keys are stored in your OS-native keychain via keytar — never in plaintext, environment variables, or config files that could be accidentally committed to version control.
Only the directory you explicitly mount with --mount or the repo you clone with --repo is indexed. Nothing outside those paths is ever touched.
Yes. Use --airgap flag with Ollama installed locally. All LLM inference, embeddings, and vector search happen entirely on your machine with zero network calls.
The /handoff command lets you transfer your full conversation context and session state to a different persona mid-session. For example, research in Scholar, then hand off to Writer to draft a report.
The router in src/utils/router.js analyzes query complexity and routes to GPT-4o-mini for simpler tasks and GPT-4o for complex ones (when using OpenAI), minimizing costs without sacrificing quality.
All persistent data is stored locally in .snapmind_cache/ — vector tables in lancedb/ and conversation history in sessions/. Use snapmind-ai maintenance to clean up stale data.
